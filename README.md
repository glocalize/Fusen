# Fusen! 📌

Webサイトレビューツール。レビューしたいサイトのURLを登録すると「キャンバス」になり、ページの上に直接ピン留めコメントを貼って、承認/修正依頼までを一気通貫で行えます。

> **これは何のためのツールか:** 自分（またはチーム）が**権利を持っている、もしくはレビューの許可を得ているサイト**——とくにステージング環境やプロトタイプ——にコメントを付けてレビューするための、自己ホスト型ツールです。第三者のサイトを無断で取り込んで利用することは想定していません。詳しくは下の「利用上の注意・免責」を参照してください。

## 起動方法

Node.js 18以上が必要です(`node --version` で確認)。

```bash
cd fusen
npm install
npm start
```

ブラウザで **http://localhost:4649** を開き、名前を入れてログインしてください(パスワード不要)。

## 使い方

1. **+ 新しいキャンバス** でレビューしたいサイトのURLを登録
2. カードをクリックするとサイトがレビュー画面で開く
3. 下部ツールバーで **📌 コメント** モードに切替 → ページ上をクリック → コメントを書いて「ペタッと貼る」
4. **👀 見る** モードに戻すとサイトを普通に回遊できる(コメントはページごとに保存)
5. **🔗 共有** でログイン不要のゲスト用リンクをコピー(名前入力だけでコメント可能)
6. **✅ レビュー完了** で「承認」または「修正依頼」を送信

## 機能

- ライブサイトのプロキシ表示+ピン留めコメント(スレッド返信・解決済み管理)
- ピンはDOM要素を毎フレーム再特定して追従(sticky・遅延読み込みでもずれない)。ホバー中の対象要素をハイライト表示
- コメントサイドバー(検索・未解決/解決済みフィルタ)
- 承認フロー(承認/修正依頼+履歴)
- ゲスト共有リンク、アーカイブ、ダッシュボード

## 技術構成

- Node.js + Express(純JSのみ、ネイティブ依存なし)
- データは `data/db.json` に保存(バックアップはこのファイルをコピーするだけ)。このフォルダは `.gitignore` で除外されており、登録URLやコメントはリポジトリに含まれません。
- プロキシ: 対象サイトのHTMLを取得し、`<base>`と注釈オーバーレイ(`public/fusen-overlay.js`)を注入して配信
- セキュリティ: プロキシはキャンバス登録ドメイン(+サブドメイン)のみ許可

## 既知の制限(v0)

- プロキシ表示ではフォーム送信不可(意図的にブロック)
- ログイン必須のサイト・複雑なSPAは表示が崩れる場合あり → 検証して問題があればスクリプトタグ埋込方式に切替予定
- 認証は名前のみの簡易方式(社内ネットワーク内での利用を想定)
- リアルタイム同期なし(リロードで他の人のコメントを取得)

## チームでの利用

社内サーバーで `PORT=80 npm start` のように起動し、社内DNSやIPでアクセスさせてください。レビュー対象のステージング環境へ到達できるネットワークに置くことが重要です。
